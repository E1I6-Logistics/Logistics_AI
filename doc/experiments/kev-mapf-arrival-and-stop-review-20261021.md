# 양보 도착·대기 위치 검토와 연속 주문 관찰

2026-10-21. 사용자가 N5·N6의 조건부 양보 사용을 허용했고, 실기체 도착 후 아루코 동작과 길목 정지의 현실성을 확인했다. **이번에 실기체 이동·아루코 실행·새 다중 양보 연결은 하지 않았다.** 운영 코드는 바꾸지 않았다.

## 결정과 남은 조건

- N5·N6는 비어 있고 집기 작업 중이 아니면 임시 양보 위치로 사용할 수 있다. 실제 연결에서는 점유·예약을 유지하여 새 픽업과 겹치지 않게 해야 한다.
- 양보에도 실제 도착·위치를 확인한다. 작업 도착과 구분하여 아루코 정렬·OMX 작업을 생략한다. 기존 실기체 내부 양보의 비최종 도착 처리를 유지하는 방향이다.
- 현재 시험은 허용 노드까지 비켜서 정지한다. 엣지 중간에 멈추면 기존 구조에서 그 물리 통로 전체를 점유한다. 중간 정차를 지원하려면 위치별 안전한 정차점·로봇 크기·통로 점유·예약·재출발을 별도로 설계해야 한다.
- N7·N10·N11에 이동 가능한 정차 로봇이 생길 가능성은 사용자도 미확정이다. 의도적 배치 시험은 허용했지만 자연 발생했다고 주장하지 않는다. 작업 중·이동 예약 중·고장·배터리 교체 로봇을 단순 IDLE로 바꾸지 않는다.
- N8 정차 적합성과 5번 시험의 N8만 허용하는 제한은 별도 확인 사항이다.

## 실기체 코드에서 확인한 구분

| 이동 상황 | 도착 후 코드 처리 |
| --- | --- |
| 일반 목적지 N3·N4·N5·N6 | 실제 좌표로 도착 확인 후 아루코 정렬 요청. 주문이 없어도 정렬 요청은 발생 |
| 기존 내부 양보·중간 도착 | 실제 좌표·점유 확인. 최종 작업 완료 콜백은 호출하지 않음 |
| 새 KEV 여러 대 양보 | 별도 시뮬레이션까지 구현. 실기체 연결·아루코 생략·후속 복귀는 아직 미검증 |

근거: [최종 도착 후 처리](../../backend/app/ros2/ros_gateway.py), [실기체 이동·도착 처리](../../backend/app/services/real_navigation.py). `RealNavigation._send()`의 `final` 조건에는 내부 양보 제외가 있고, `_check_arrival()`은 `final`일 때만 최종 콜백을 호출한다. 콜백 구분을 없애거나 일반 이동을 그대로 요청하면 양보 의도가 보존되지 않을 수 있다.

분리된 확인 두 종류를 수행했다. ROS 전송·최종 콜백 등을 모의 객체로 바꿔 실제 명령은 보내지 않았다. 이는 전체 양보 수명주기나 실기체 시험의 대체가 아니다.

- 일반 목적지 N5의 아루코 요청 확인 (`logs/traffic-recovery/arrival-policy-review-20261021/gateway-check.json`, 로컬 보관).
- 최종·비최종 도착의 콜백 구분 확인 (`logs/traffic-recovery/arrival-policy-review-20261021/internal-arrival-check.json`, 로컬 보관). 두 경우 모두 도착 노드 N5를 확인하고, 최종 도착일 때만 작업 완료 콜백 호출.

## 연속 주문 관찰

기존 `continuous_ai_orders` 자동 공급과 관제 API를 사용했다. 가상 로봇 세 대는 홈 N0·N1·N2에서 출발했다. 초기 주문 3건, 이후 5초 간격, 대기 주문 상한 3건, 시드 42, 모델 `kev-08b`이며 생성 12건에서 공급을 중지하고 접수된 주문의 완료·복귀를 기다렸다. 경로는 A*, 일반 주문 교통 선택은 KEV 설정이다. 새 여러 대 양보 탐색을 호출한 시험이 아니다.

| 항목 | 결과 |
| --- | --- |
| 생성·완료 주문 | 12건 / 12건 |
| 총 물품 | 33개 |
| 마지막 복귀까지 관찰 | 약 114.39초 |
| 점유 관찰 | 186회 |
| 관찰 도구에 보고된 실패·중복 점유 | 0건 |
| 최종 로봇 | R1=N0, R2=N1, R3=N2 / 모두 IDLE |
| 기존 272건 주문 기록 | 내용 변경 0건. 전체 284건 = 완료 271 + 취소 13 |

관찰한 N7·N10·N11·N8·N9·N12에서는 점유 노드로 기록된 정지가 없었다. ‘같은 노드 점유·엣지 점유 없음·위치 차이 2cm 이하·1초 이상’ 기준의 정지도 없었다. 기록 간격은 약 0.6초이며 짧은 정지는 놓칠 수 있다. 따라서 자연 발생 막힘을 확보했다고 보지 않는다. 실제 로봇에서도 안 생긴다는 결론도 아니다.

의도적 다중 양보 시험과 일반 주문 시험을 구분해서 유지한다. 다음 비교에서 인위적으로 만든 정지 상태임을 표시하고, 자연 발생 사례는 충분한 입력·예약·이동 의도를 함께 확보한 뒤 별도로 재현해야 한다.
